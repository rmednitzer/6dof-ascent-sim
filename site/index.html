6-DOF Launch Vehicle
Ascent Simulation

A high-fidelity six-degree-of-freedom simulation of a two-stage orbital launch vehicle — from ignition through low-Earth-orbit insertion — with full guidance, navigation & control, safety systems, structural dynamics, and telemetry.

What it models

Every major subsystem of an orbital ascent, integrated at 100 Hz and validated against authoritative references.

🚀

6-DOF rigid-body dynamics

Quaternion attitude (scalar-last), RK4 integration at a 100 Hz fixed timestep.

🌍

WGS84 gravity, J2–J6

Zonal harmonics from the analytic geopotential gradient, verified to ~1e-10.

💨

US Standard Atmosphere 1976

Altitude-dependent density with wind profile and gusts.

🔥

Two-stage propulsion

Pressure-dependent thrust with conserved mass flow and ignition/shutdown transients.

🎯

Three-phase guidance

Vertical rise, gravity turn, and Powered Explicit Guidance (PEG) for insertion.

🎛️

PID + TVC control

Gain-scheduled attitude control driving a second-order thrust-vector actuator.

🛰️

12-state EKF navigation

Position, velocity, accel-bias and gyro-bias estimation with sensor models.

🛡️

Safety systems

Boundary enforcement, health monitoring, and an autonomous flight-termination system.

〰️

Structural dynamics

Live flex-body bending modes stabilised by a frequency-scheduled notch filter, plus propellant slosh.

🎲

Monte Carlo

Parallel dispersion campaigns with an experimental SLURM HPC backend.

Quick start

Install, run the simulation, and generate the visualizations above.

git clone https://github.com/rmednitzer/6dof-ascent-sim
cd 6dof-ascent-sim
pip install -e ".[dev]"

python -m sim.main                 # run the full ascent
python examples/run_and_visualize.py   # dashboard + ground track
pytest tests/ -v                   # run the test suite
